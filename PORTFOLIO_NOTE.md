# Portfolio Note

This project is presented as an independent research and engineering project.

It is not intended to demonstrate that I can predict markets.

It is intended to demonstrate that I can:

- take an uncertain real-world problem,
- turn it into measurable questions,
- build tools to investigate those questions,
- challenge my own assumptions,
- handle large datasets,
- automate experiments,
- and stop when the evidence does not justify continuing.

The project became valuable precisely because the final answer was not perfect.

I learned more from discovering where the strategy failed than I would have learned from a backtest that only went upward.
