# Future Work

This project is closed as a trading-strategy development project, but it created several future research directions.

Possible extensions:

- formal walk-forward validation,
- bootstrap analysis of trade sequences,
- Monte Carlo drawdown simulation,
- regime classification using volatility and trend measures,
- parameter sensitivity maps,
- cross-market replication,
- more rigorous multiple-hypothesis correction,
- confidence intervals for conditional pattern probabilities,
- and independent reproduction of results using a second backtesting engine.

The priority for future work would be stronger statistical methodology rather than adding more indicators.
