# What I Learned

This project taught me several lessons that apply far beyond trading.

## Data can disagree with intuition

A strategy can feel convincing and still become weak when the sample expands.

## More complexity is not automatically better

Adding filters can improve a backtest while reducing real robustness.

## Negative results matter

Ending a project because the evidence is weak is better than forcing it to succeed.

## Risk is a separate problem

A strategy can have positive expectancy and still be impractical because of drawdown.

## Good research tries to fail

The strongest test is not the one that confirms the idea.

It is the one designed to expose where the idea breaks.

## Programming changes how I learn mathematics

Concepts such as expected value, conditional probability, and z-scores became much more meaningful when I had to use them on real datasets instead of only solving textbook exercises.
